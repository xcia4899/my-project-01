# 🛒 Horizon Shop

一個以 **Vue.js** 製作的電商平台，專門販售 3C 配件商品。整合動畫與購物車功能，提供流暢的使用者體驗。

---

## ✨ 專案特色 Features

- 🖼️ 商品自動載入與篩選
- 🛍️ 購物車功能（localStorage 儲存）
- 📦 商品詳細頁
- 🔄 分頁顯示與過濾功能
- 📱 RWD 響應式設計支援手機與桌面裝置

---

## 🖥️ 技術棧 Tech Stack

| 技術 | 說明 |
|------|------|
| [Vue 3](https://vuejs.org/) | 前端框架 |
| SCSS / CSS | 樣式設計與 RWD |
| JSON / Local API | 商品資料模擬與串接 |
| localStorage | 儲存購物車內容與使用者選擇 |
